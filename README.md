# Quantech × Christmas 🎄

**The Merry Estimate** — a festive puzzle collection for Quantech’s Christmas social and mock BrownBags.

Cost-analysis terminology, familiar surnames, and a few carefully placed distractions—all in one self-contained HTML file.

## The games

### Cost Connections

Three boards, each containing 16 tiles and four hidden groups.

- Select four tiles that share a connection.
- Find all four groups before making four mistakes.
- Read the explanation after each successful match.
- Watch for names that return with different meanings!

### Five-Letter Forecast

Eight five-letter cost-analysis word puzzles, with six guesses per word.

- **Green:** Correct letter, correct position.
- **Gold:** Correct letter, different position.
- **Gray:** No remaining match for that letter.
- Any five-letter A–Z guess is accepted.
- Optional definition hints are recorded on your scorecard.

## How to play

Open the GitHub Pages website on a desktop or mobile browser. No account or installation is required.

You can also download `index.html` and open it directly in your browser to play offline.

Start with Connections, then use **Next puzzle** to continue through the word games. The finale celebrates your run and shows your overall results.

## Progress and results

Progress saves in your browser when storage is available.

The results screen tracks:

- Connections boards solved and groups found
- Connections mistakes
- Word puzzles solved and guesses used
- Definition hints used
- Unfinished puzzles you can return to

Revealed answers count as **finished**, not **solved**. Restarting a puzzle replaces its result. Progress is local to each browser; there is no shared leaderboard.

## For the party host

Play individually, in teams, or together on a projector.

The **Host desk & answers** contains the answer key and explanations. This is a friendly, honor-system game—the answers are included in the HTML.

## Hosting and updates

GitHub Pages publishes from the `main` branch and `/ (root)` folder.

To update the game, replace `index.html` and commit the change. The website updates at the same address.

The game needs no external libraries, build tools, or server-side services.
